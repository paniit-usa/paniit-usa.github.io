1. How it works

Most pages on this site show the contents of a Google Doc that you own. When you edit the Doc, the website updates by itself, usually within about 5 minutes. You never touch the website directly.

  • Public pages (Home, Administrative, Player Resources) each show one Google Doc that has been published to the web.
  • Volunteer material (Onboarding) lives in a separate, private Drive folder. The website only links to it, and Google lets in only the people you have shared it with.
  • The Bridge Calendar on the Home page is a Google Calendar you manage.

The setup below is done once. After that, the site builder pastes your links into the site one time, and from then on you just edit your Docs.

2. Step 1: Create the folders

One manager creates the folders below in their Google Drive, then shares the top folder with the other two managers as Editor (right-click the folder → Share → add their emails → Editor). Please also share it with the site builder as Editor, so they can help if something breaks.

📁 PANIIT Bridge Website ← public content, shared with the 3 managers 📁 1 Home Page 📁 2 Administrative 📁 3 Player Resources 📁 PANIIT Bridge Volunteers (Private) ← never published; shared only with volunteers
Keep the two top folders separate. Do not put the private folder inside the public one. That keeps volunteer material from being shared or published by accident.

Writing tips: The site already shows the page title, so start the Doc with your first paragraph or a heading, not the title again. Use Google Docs' built-in Heading styles, bullet lists and links; they all carry over. Keep the Home page Docs short, because they appear in small boxes.

4. Step 3: Publish each Doc to the web

Do this once for each of the 13 Docs:

  1. Open the Doc.
  2. Click File → Share → Publish to web.
  3. Leave the Link tab selected and click Publish, then OK.
  4. Open Published content & settings (at the bottom of that window) and make sure "Automatically republish when changes are made" is ticked.
  5. Copy the link shown (it ends in /pub) and paste it into your list for Step 6.
"Publish to web" makes the Doc readable by anyone with the link, the same as the website. It does not let anyone edit it. Only publish Docs from the PANIIT Bridge Website folder.

If Publish to web is greyed out, you are probably using a work or university Google account whose administrator has turned it off. Please use a personal Gmail account instead.

5. Step 4: Create the Bridge Calendar

  1. Go to Google Calendar. In the left panel, next to Other calendars, click + → Create new calendar.
  2. Name it PANIIT Bridge Calendar and click Create calendar.
  3. In that calendar's settings, under Share with specific people, add the other two managers with "Make changes to events".
  4. Under Access permissions for events, tick "Make available to public".
  5. Under Integrate calendar, find Embed code. Copy only the web address inside src="…" (it starts with https://calendar.google.com/calendar/embed?src=) for Step 6.

Add PANIIT tournaments and any other bridge events you'd like players to know about. Events appear on the Home page automatically.

6. Step 5: Set up the private volunteer folder

In PANIIT Bridge Volunteers (Private), create these Docs (or upload existing files):

Google Doc nameWhat goes in it
TD ResourcesGuides, checklists and references for tournament directors
Conflict Resolution ProcessStep-by-step process for handling disputes between players

Then set who can see it:

  1. Right-click the folder → Share.
  2. Under General access, make sure it says Restricted.
  3. Add each volunteer's email as Viewer (or Editor for people who help maintain the material).
  4. Click Copy link and keep it for Step 6.
Never use "Publish to web" or "Anyone with the link" on anything in this folder. To give a new volunteer access, add their email to the folder; to remove someone, remove their email. The website link never needs to change.

7. Step 6: Send the links to the site builder

Email the site builder one message listing the links, for example:

Home – Announcements: https://docs.google.com/document/d/e/…/pub Home – Newsletter: https://docs.google.com/document/d/e/…/pub … (one line for each of the 13 Docs) Bridge Calendar embed: https://calendar.google.com/calendar/embed?src=… Volunteers (Private) folder: https://drive.google.com/drive/folders/…

The site builder adds them to the website once. You can send links in batches; any page without a link keeps showing its current text until its link arrives.

8. Day-to-day editing

  • To change a page: open its Doc in the PANIIT Bridge Website folder and edit. The site updates within about 5 minutes. Refresh the page to check.
  • To add an event: add it to the PANIIT Bridge Calendar.
  • Newsletter and anecdotes: when community members send in items, paste the ones you choose into Home – Newsletter or Home – From the Table. Remove older items to keep the boxes short.
  • Two managers editing at once is fine. Google Docs handles it, and File → Version history lets you undo mistakes.
  • Need a new page or a menu change? Ask the site builder; that is the only thing that needs them.

9. Golden rules

  1. Edit Docs; never delete and recreate them. A new Doc has a new link, and the website would keep showing the old one. If a page needs a complete rewrite, clear the text in the existing Doc.
  2. Renaming or moving a Doc within the folder is fine. The link does not change.
  3. Don't click "Stop publishing" unless you want that page to go blank on the website.
  4. Everything in the Website folder is public. Don't include personal phone numbers or emails without the person's permission.
  5. Nothing in the Volunteers (Private) folder is ever published.
  6. Keep at least two managers as Editors on both folders, so nothing is lost if someone steps away. If the folder owner steps down, they should transfer ownership to another manager (Share → ⋮ next to the person → Transfer ownership).
